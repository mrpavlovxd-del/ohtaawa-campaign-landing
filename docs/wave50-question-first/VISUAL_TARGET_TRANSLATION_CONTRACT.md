# Wave50 visual target translation contract

## Binding target

Current Wave45 production/root at `origin/main` is the visual target and `reused-reference`. Wave50 is not a redesign.

## Must remain unchanged

- Hero photography/crops, price hierarchy, typography and trust rail.
- All real proof, service scope, guarantee, timing, reviews, location and FAQ.
- Graphite/ivory/green palette, spacing, square geometry, focus and dialog behavior.
- One primary code-native action and one secondary scope anchor in the hero.

## Allowed delta

- One consistent question-first CTA label.
- Contact-sheet headline, explanatory sentence and prepared messenger text aligned to the same lower-commitment intent.
- One conditional-sequencing clarification beside the hero CTA: answer first, consultation with the unchanged free wash only if the visitor chooses to come.
- Dedicated diagnostic event attributes.

## Translation loss limits

- Pixel/layout structure should remain materially identical to Wave45 except for text width/wrapping caused by the approved label.
- CTA remains visible without clipping at 1440, 430, 390 and 360 px.
- No direct-channel panel, sticky bar, new media, new proof or new claim.
- Controls remain semantic, keyboard accessible and code-native.
