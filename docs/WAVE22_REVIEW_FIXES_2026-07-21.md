# Закрытие независимого ревью wave22

Дата проверки: 21.07.2026.

## Что исправлено

- Вариант включается только явным параметром `experiment_id=wave22_ya_search_polish_proof_first`. Совпадение одного `utm_campaign` больше не может случайно активировать эксперимент.
- Реальное фото «до/после», предоставленное владельцем, не загружается в контрольной версии и включается только внутри wave22.
- Сгенерированное изображение процесса имеет нейтральную подпись «Иллюстрация процесса полировки кузова» и техническую маркировку `generated-illustrative`; оно не выдается за выполненную работу OHTAAWA.
- Раздел отзывов и навигация `#reviews` снова доступны в варианте. Нерелевантная карточка про пленку скрыта, заголовок и пояснение адаптированы под полировку.
- Для экранов 320-380 px уплотнена только вертикальная композиция hero. Telegram и звонок полностью помещаются в первом экране.
- Отдельный рекламный номер `+7 (812) 767-88-40` сохранен: это ранее созданный и проверенный канал Mango `OHTAAWA wave4 ads`, а не случайная подмена основного номера.

## Проверки

- `node --test tests/wave22-static.test.cjs`: 3 из 3 тестов пройдены.
- `tests/wave22-browser-qa.cjs`: пройдены 320x568, 360x640, 390x844 и 1440x1000.
- На всех размерах нет горизонтального переполнения; hero CTA находится в первом экране.
- Контрольный URL с тем же `utm_campaign`, но без `experiment_id`, не активирует wave22 и не запрашивает скрытое proof-изображение.
- В wave22 загружаются real proof и иллюстрация процесса; отзывы видимы.
- Клик Telegram формирует событие с правильными `experiment_id`, `scenario=used-car`, `location=hero` и `destination=telegram`.
- Ошибок JavaScript и консольных ошибок в прогоне не обнаружено.
