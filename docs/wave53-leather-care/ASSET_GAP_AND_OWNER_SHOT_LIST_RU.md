# Asset gap и owner shot list — Wave53

## Что найдено

Один реальный файл из текущего публичного бренд-пака показывает работу с кожаным сиденьем и пригоден для Draft hero после truthful crop. Он не подтверждён как работа OHTAAWA/Wave53, не показывает Koch и имеет незакрытый rights/context owner gate.

Сгенерированный интерьерный кадр обнаружен и сознательно исключён из Wave53.

## Заблокированные placement/claims

До получения подтверждённых real assets нельзя публиковать:

- gallery «наши работы»;
- before/after;
- подписи «наносим Koch» поверх текущего кадра;
- утверждения о результате конкретного автомобиля;
- production hero, если владелец не подтверждает права/контекст текущего брендового файла.

## Минимальный owner shot list

1. `LC-01 hero-process-wide`: горизонтальный 3:2 или 16:10, реальное кожаное сиденье/дверная карта, рука мастера и мягкая щётка/салфетка, чистый свет, без лица, номера, VIN, ключей и личных вещей; 2400 px по ширине.
2. `LC-02 koch-application-macro`: крупный план нанесения именно используемого кондиционера Koch; упаковка может быть видна только если продукт и маркировка подтверждены; 1800 px.
3. `LC-03 truthful-after-same-surface`: тот же участок после работы, тот же свет/ракурс; без искусственного усиления цвета и без обещания «как новый».
4. Опционально `LC-04 condition-macro`: сухость/загрязнение без персональных деталей, если есть согласие владельца автомобиля.

Для каждого файла нужны: дата, автор/источник, согласие на web-рекламу, связь с реальной услугой, статус автомобиля/клиента, разрешённые crop, privacy review. Автоматический blur не считается доказательством приватности; финальный crop проверяется вручную на 100%.
