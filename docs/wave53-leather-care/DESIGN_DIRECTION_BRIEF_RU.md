# Design direction — «Тихий ритуал ухода»

## Задача

Сделать недорогую по сравнению с плёнкой услугу визуально профессиональной, но не превращать её в «люксовую магию». Пользователь должен за несколько секунд увидеть точную услугу, цену и безопасный следующий шаг.

## Архитектура

1. Hero: реальный интерьерный процесс, точный оффер, цена, CTA ближайшего времени.
2. Состав: три проверяемых действия без расплывчатого пакета химчистки.
3. Когда услуга уместна: загрязнение, сухость, потеря ухоженного вида — без диагностики повреждений.
4. Care protocol: осмотр → деликатная очистка → кондиционер и ручная проверка.
5. Trust: границы услуги, отдельное согласование допработ, внешние отзывы без выдуманных цитат.
6. Повтор цены и low-friction CTA.
7. Адрес, маршрут, реальные контакты.

## Визуальный язык

- Graphite base, warm ivory typography, restrained forest-green action color.
- Тёплый cognac leather применяется локально как материал услуги, не как page-wide tint.
- Сетка асимметричная редакционная; крупные пустые поля и тонкие «швы» вместо набора карточек.
- Signature component: вертикальная care line со стежками/номерами этапов; это семантический список, а не декоративная схема.
- Serif — для коротких ключевых заголовков, sans — для условий и действий.
- Motion: только state feedback, dialog and short reveal; reduced-motion полностью отключает reveal transitions.

## Anti-DNA

Не копировать film hero/trust rail, не использовать image carousel без честных case assets, не показывать full dry-cleaning equipment как обещание, не писать «восстановим», «уберём любые повреждения», «как новый», не использовать фальшивый scarcity/countdown и не выдавать generated интерьер за OHTAAWA proof.

## Copy constraints

- «Чистка кожи и кондиционер Koch — 3 500 ₽» сохраняется дословно.
- «Узнать ближайшее время» — primary CTA.
- Допработы и реставрация не входят автоматически.
- Не обещать длительность, если она не подтверждена source contract.
- Не утверждать химический/медицинский эффект, безопасность для всех типов кожи или конкретный результат до осмотра.
