# QA-отчет wave22

- Проверено: 21.07.2026.
- Вариант: `wave22_ya_search_polish_proof_first`.
- Контур: отдельная предпродакшен-ветка; опубликованная wave18 не изменена.

## Функциональные доказательства

- Вариант включается только явным параметром `experiment_id`.
- Без параметра работает прежняя универсальная посадочная.
- Основной маршрут: Telegram с подготовленным запросом оценки по фото.
- Второй маршрут: звонок на отдельный рекламный номер.
- В варианте остается только цена полировки.
- Изображение процесса переключается с пленки на полировку.
- Реальный материал владельца «до/после» не выдается за генерацию или чужую работу.
- Smoke аналитики подтвердил события просмотра доказательства, цены, scroll 50/90, условий и Telegram CTA с UTM и experiment ID.

## Визуальные доказательства

- Desktop 1440 x 1100: горизонтального переполнения нет, следующий блок виден под первым экраном.
- Mobile 390 x 844: переполнения нет, высота hero 741,875 px, начало следующего блока остается видимым.
- На первом экране только два однозначных действия: Telegram и звонок.
- Финальный мобильный проход устранил пустую темную область под кнопками.
- Артефакты: `proof/2026-07-21-wave22/desktop-v3-hero.png` и `mobile-v3-hero.png`.

## Решение

- Готово к отдельной контролируемой когорте после достижения wave18 точки остановки или лида.
- Статистику wave18 и wave22 не смешивать.
- Остановить wave22 на 20 чистых кликах или 700 рублях без квалифицированного диалога.
- Просмотры цены/доказательства и клики CTA сами по себе не основание для масштабирования.
